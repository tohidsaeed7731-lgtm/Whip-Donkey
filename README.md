# پنج ضربه تا عرعر! 🫏

یک بازی کوچک و بامزه‌ی فارسی برای مرورگر: شلاق به‌دنبال نشانگر موس حرکت می‌کند و با هر کلیک یک ضربه ثبت می‌شود. در ضربه‌ی پنجم، مهمان ویژه با انیمیشن وارد می‌شود و صدای عرعر پخش می‌کند!

## اجرای بازی

نسخه‌ی آنلاین پروژه از بخش **Deployments** همین مخزن در دسترس است.

برای اجرای نسخه‌ی ساده و بدون نصب نیز می‌توانید فایل `index.html` را مستقیماً در مرورگر باز کنید.

## امکانات

- شلاق متحرک و دنبال‌کننده‌ی موس
- شمارنده‌ی تصویری پنج ضربه
- افکت برخورد در محل کلیک
- کاراکتر خر کارتونی با انیمیشن ورود
- تولید صدای عرعر با Web Audio API و بدون فایل صوتی خارجی
- پشتیبانی از موس، لمس و صفحه‌نمایش موبایل
- رابط کاملاً فارسی و راست‌چین

## اجرای نسخه‌ی توسعه

به Node.js نسخه‌ی ۲۲ یا جدیدتر نیاز دارید:

```bash
npm install
npm run dev
```

سپس نشانی نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

## ساخت نسخه‌ی نهایی

```bash
npm run build
```

## فناوری‌ها

Next.js، React، TypeScript، CSS و Web Audio API
